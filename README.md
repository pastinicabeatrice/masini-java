# Mașini

Exemplu despre clonare și copierea referințelor în Java.

## Ce conține

- clasa `Car` cu producător, preț, tip de combustibil (enum `FuelType`) și un vector de distanțe
- metoda `clone()` și diferența dintre copierea superficială și cea în adâncime
- copierea defensivă a vectorului în getter și setter
- imutabilitatea obiectelor `String`

## Rulare

Se deschide folderul în IntelliJ IDEA și se rulează `app.main.Main`.
